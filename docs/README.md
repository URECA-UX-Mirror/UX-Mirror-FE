# 프로젝트 문서

이 디렉터리는 프론트엔드가 백엔드와 연동하기 위해 필요한 구조·표시 규칙·환경 정보를 책임별로 나눈다. 문서는 원칙적으로 300줄 이하로 유지한다. 화면 목록과 실행 방법은 루트 [README](../README.md)에 있다.

## 계약 정본

API와 데이터 구조의 정본은 **인터페이스·데이터 계약서 v1.3.2**(이하 계약서)다. 이 저장소의 계약 문서는 계약서를 복사하지 않고, 프론트가 소비하는 필드와 표시·오류 처리 규칙만 정리한다. 계약서의 절번호는 `계약 §17.2`처럼 적는다. 계약서가 바뀌면 해당 문서와 [미결정 항목](operations/open_issue.md)을 같은 작업에서 갱신한다.

| 영역 | 문서 | 설명 |
| --- | --- | --- |
| 구조 | [프론트엔드 구조](architecture/frontend-structure.md) | 화면별 사용 API·상태 관리, 표시 규칙, Adapter 계층, 폴더 구조 |
| 계약 | [REST API](contracts/rest-api.md) | endpoint별 요청·응답·오류·빈 데이터 처리 |
| 계약 | [데이터 모델](contracts/data-model.md) | 프론트가 소비하는 타입과 식별자 정책 |
| 계약 | [실행 상태와 폴링](contracts/run-lifecycle.md) | 상태값, 폴링, 새로고침 복원 |
| 계약 | [스크린샷과 bbox](contracts/screenshot-bbox.md) | 이미지 표시와 bbox 좌표 변환 |
| 계약 | [지표와 목표 판정](contracts/metrics-and-goal.md) | 지표 의미, 목표 판정, 프론트의 책임 범위 |
| 운영 | [로컬 환경](operations/local-environment.md) | 포트, 환경변수, CORS, 비밀값 규칙 |

| 규칙 | [저장소 작업 지침](../AGENTS.md) | 읽기 범위, 문서·테스트·Git 규칙 |

## 표기 규칙

| 표기 | 의미 |
| --- | --- |
| `계약 §n` | 계약서에 정의된 값. 절번호가 근거다 |
| `임시` | 계약서에 없어 프론트가 먼저 정한 값. 확정 전까지 바뀔 수 있으며 `OI-n`으로 [미결정 항목](operations/open_issue.md)에 연결된다 |
| `P1` | 현재 구현 범위(P0) 밖. 구현된 기능으로 취급하지 않는다 |

백엔드 API는 아직 구현되지 않았다. 계약서의 모듈별 반영 상태 표가 구현 현황의 기준이다. JSON 예시는 계약서 예시 또는 `임시` 예시로 표시한다.
