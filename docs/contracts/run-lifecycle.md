# 실행 상태와 폴링

분석 실행은 비동기다. 프론트는 `POST /api/runs`로 `runId`를 받은 뒤 `GET /api/runs/{runId}`를 주기적으로 호출해 상태를 확인한다. 백엔드가 실행을 어떤 기술로 처리하는지는 정해지지 않았고 프론트도 가정하지 않는다.

## 상태값

| 값 | 의미 | 종료 상태 | 출처 |
| --- | --- | --- | --- |
| `RUNNING` | 실행 중 | 아니오 | `임시` |
| `SUCCESS` | 목표 화면에 도달해 종료 | 예 | `임시` |
| `MAX_STEPS` | 최대 탐색 횟수에 도달해 종료 | 예 | `임시` |
| `BLOCKED` | 더 진행할 수 없어 종료(후보 없음 등) | 예 | `임시` |
| `TIMEOUT` | 제한 시간 초과로 종료 | 예 | `임시` |
| `ERROR` | 실행 오류로 종료 | 예 | `임시` |

- 위 여섯 값은 팀 기획에서 가져온 것이며 백엔드 코드에는 아직 같은 값이 없다. 값이 확정되면 `RunStatus`와 이 표를 함께 고친다. [OI-3](../operations/open_issue.md#oi-3)
- **제안(확정 아님)**: `PENDING`(접수됨, 실행 전). 도입 여부가 정해질 때까지 프론트는 모르는 상태값을 `RUNNING`처럼 진행 중으로 처리하고 오류로 만들지 않는다.
- 종료 상태는 `RUNNING`과 모르는 값(진행 중으로 간주)을 제외한 위 다섯 값이다. 종료 상태 판정은 한 함수에서만 한다.
- `SUCCESS`는 목표 도달(`summary.goalReached = true`)에 대응한다. 목표 도달 판정은 백엔드가 하며 [지표와 목표 판정](metrics-and-goal.md#목표-도달-판정)에 있다.

## 폴링 규칙 (`임시`)

| 항목 | 규칙 |
| --- | --- |
| 간격 | 2초(임시 권장값, 확정 아님). 설정 값 한 곳에서 바꾼다. [OI-5](../operations/open_issue.md#oi-5) |
| 시작 | `POST /api/runs` 응답으로 `runId`를 받으면 진행 화면에서 즉시 1회 조회하고 이후 간격마다 반복 |
| 중단 | 응답 `status`가 종료 상태이거나, 진행 화면을 떠나거나, `404`를 받은 때 |
| 단계 조회 | Run을 조회할 때마다 `steps`도 함께 조회한다. 종료 응답을 받은 뒤 `steps`를 한 번 더 조회해 마지막 단계를 반영한다 |
| 중복 방지 | 이전 요청이 끝나기 전에는 다음 요청을 보내지 않는다. 같은 `runId`에는 폴링 루프를 하나만 둔다 |
| 정리 | 화면 이탈 시 타이머와 진행 중인 요청을 취소한다(`AbortController`) |
| 종료 후 | 진행 화면은 "분석 결과 보기"를 활성화한다. 자동 이동은 하지 않고 사용자가 누르면 결과 화면으로 간다 |

## 오류 처리

| 상황 | 처리 |
| --- | --- |
| 네트워크 오류·5xx | 폴링을 멈추지 않고 간격을 늘려(2초 → 4초 → 8초, 상한 10초) 재시도하고 "연결 재시도 중"을 표시. 성공하면 간격을 되돌린다 |
| 연속 실패 | 5회 연속 실패하면 폴링을 멈추고 수동 재시도 버튼을 보인다 |
| 404 | 폴링 중단. "실행을 찾을 수 없음" 화면과 새 분석 이동을 제공 |
| 응답 형식 오류 | Adapter에서 오류로 처리하고 화면에는 일반 오류 안내만 보인다 |

재시도 횟수와 간격은 `임시`이며 구현 단계에서 값을 조정할 수 있다.

## 새로고침 뒤 복원

1. 진행 화면과 결과 화면은 `runId`를 URL에 담는다.
2. 새로고침하면 URL의 `runId`로 `GET /api/runs/{runId}`를 호출한다.
3. 종료 상태면 폴링 없이 결과를 표시하고, 진행 중이면 폴링을 다시 시작한다.
4. 화면 상태(열람 중인 단계, 펼침 여부)는 복원하지 않는다. 열람 중인 단계는 최신 단계로 초기화한다.

새 분석 화면의 "마지막 Run" 표시는 Run 목록 API가 정해질 때까지 `localStorage`에 기록한 `runId`로 대신한다. 저장소를 읽거나 쓰지 못해도 화면은 동작해야 한다. [OI-8](../operations/open_issue.md#oi-8)

## 동시 실행

- 한 번에 몇 개의 Run을 실행할 수 있는지는 정해지지 않았다. [OI-5](../operations/open_issue.md#oi-5)
- 프론트는 `409`를 받으면 "진행 중인 분석이 있습니다" 안내를 보이고, 같은 화면에서 두 variant를 동시에 시작하지 않고 순서대로 시작한다.
